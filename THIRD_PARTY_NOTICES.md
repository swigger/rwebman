# Frontend third-party notices

The following unmodified browser bundles are embedded in the rwebman executable. They are served locally; no CDN request is made at runtime.

| Package | Version | Files | License |
| --- | --- | --- | --- |
| @xterm/xterm | 5.5.0 | web/vendor/xterm.js, web/vendor/xterm.css | MIT, full text in web/vendor/LICENSE.xterm |
| @xterm/addon-fit | 0.10.0 | web/vendor/addon-fit.js | MIT, full text in web/vendor/LICENSE.addon-fit |

Source: https://github.com/xtermjs/xterm.js

The browser bundles were obtained from the corresponding versioned npm packages via jsDelivr. The exact Rust dependency set is recorded in Cargo.lock; individual crates retain their upstream licenses.
